Job Description

Java Backend Developer

Location: Toronto

Job Type: Full-Time, Permanent

Experience Required: 3–7 Years

Job Overview

We are seeking a skilled and motivated Java Backend Developer to join our
growing team. In this role, you will collaborate with architects, technical
leads, and fellow developers to design, develop, and deploy scalable backend
solutions. You will play a key role in building robust microservices and high-
performance systems that support mission-critical applications.

Key Responsibilities

* Collaborate with Systems Architects, Software Team Leads, and Developers to design and implement technical solutions
* Develop and maintain backend services using Java and Spring Boot
* Design and implement microservices-based architectures
* Build and integrate RESTful APIs for internal and external systems
* Work with Kafka for event-driven architecture and messaging systems
* Analyze complex requirements and translate them into scalable technical solutions
* Design, develop, and troubleshoot database applications
* Prepare and document technical designs, system architecture, and project estimates
* Ensure code quality by adhering to industry standards and internal development guidelines
* Participate in code reviews and collaborate with peers to maintain best practices

Required Skills & Qualifications

* 3 to 7 years of experience in backend development
* Strong proficiency in Java and Spring Boot
* Hands-on experience with Microservices Architecture
* Experience designing and consuming REST APIs
* Working knowledge of Apache Kafka or similar messaging systems
* Solid understanding of software design patterns and system architecture
* Experience with relational and/or NoSQL databases
* Strong problem-solving and analytical skills
* Excellent communication and teamwork abilities

Nice-to-Have Skills

* Experience with cloud platforms (AWS, Azure, or GCP)
* Familiarity with containerization tools (Docker, Kubernetes)
* Knowledge of CI/CD pipelines and DevOps practices
* Experience with Agile/Scrum methodologies

What We Offer

* Competitive salary and benefits package
* Hybrid work model (Toronto or Calgary)
* Opportunities for career growth and advancement

Collaborative and innovative work environment
