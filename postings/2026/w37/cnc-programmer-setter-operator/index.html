Job Description

# Job description

We are looking for an experienced CNC Programmer/Setter/Operator. You will be
responsible for creating 3D CAD files for stone cutting CNC machines to
produce high quality stone products, ensuring that our systems run efficiently
and are properly maintained. Ideally, this position requires strong mechanical
aptitude and an interest in machinery. Position is available immediately. Only
serious candidates who meet the requirements will be contacted.

Core Competencies Required:

Programming and setting ¾ axis CNC mill and router

Proficiency with MasterCam & Solidworks

Proficiency with G&M code programming

Ability to read and interpret technical drawings

Understand geometric dimensioning and tolerances

Attention to detail and quality requirements

Adaptability and conceptualization

Excellent problem solving skills

Interpersonal communication, follow verbal and written instructions

Organizational Skills

Availability to work weekends and overtime

Ability to lift up to 25 pounds for short periods of time

Ability to drive a forklift

Job Duties

Translate blueprints into 3D models

Programming and setting CNC machines (CNC 625 with added optional 32” blade;
CNC Northwood (USA); CNC Prussani (Italy); 4 Axis CNC 18” machine; CNC machine
for balusters, bases and capitol; CNC Stone Carving Machine for columns; 2
profile CNC machines for straight profile cutting; CNC bridge saw with 48”
blade to cut 16” stone slabs)

Quality control

Program using MasterCam

G&M code programming

Promote a safe and healthy working environment by maintaining housekeeping
standards and safe working practices

Other duties as assigned

Requirements:

Previous experience is preferable. Russian/Ukrainian language is an asset.

Expected Start Date: ASAP

Job Type: Full-time

Salary: $28.00-$30.00 per hour
